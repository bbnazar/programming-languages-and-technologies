# Лабораторная работа №11 — React (props и state)

- `variant3-theme` — вариант 3, переключатель темы (ThemeSwitch, Preview)
- `variant9-courses` — вариант 9, каталог курсов (CourseCard, CourseInfo)
- `variant15-quiz` — вариант 15, викторина (QuestionCard)

## Запуск
```
cd variant3-theme
npm install
npm run dev
```
(В PowerShell, если ошибка про скрипты, писать `npm.cmd install` и `npm.cmd run dev`.)

## Props и state

**Вариант 3.** App передаёт в ThemeSwitch `title` и `themes`. ThemeSwitch хранит в state `selected` (выбранная тема) и `clicks` (сколько раз меняли), передаёт тему в Preview через props.

**Вариант 9.** App хранит `selectedId` (выбранный курс) и `myCourses` (на что записался). CourseCard получает `name`, `short`, `hours`, `selected`, `enrolled`, `onClick`. CourseInfo получает `course`, `enrolled`, `onEnroll`, `onClose`.

**Вариант 15.** App хранит `index` (текущий вопрос), `answers` (ответы) и `score` (счёт). QuestionCard получает `number`, `count`, `data`, `onAnswer`, `onSkip`.
