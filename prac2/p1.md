## Задание 3. Базовый уровень

### Условие

Ввести длину и ширину прямоугольника. Определить его площадь, периметр и длину диагонали.

### Теоретические сведения

Для прямоугольника используются следующие формулы:

* Площадь:

  **S = a · b**

* Периметр:

  **P = 2 · (a + b)**

* Диагональ:

  **d = √(a² + b²)**

где `a` — длина прямоугольника, `b` — его ширина.

### Код программы

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b;

    cout << "Введите длину и ширину: ";
    cin >> a >> b;

    double S = a * b;
    double P = 2 * (a + b);
    double d = sqrt(a * a + b * b);

    cout << "Площадь: " << S << endl;
    cout << "Периметр: " << P << endl;
    cout << "Диагональ: " << d << endl;

    return 0;
}
```

### Результат работы

Например, если длина прямоугольника равна `5`, а ширина `3`, программа вычислит:

* площадь: `15`;
* периметр: `16`;
* диагональ: `5.83`.

### Вывод

В результате выполнения задания была создана программа, которая по заданным длине и ширине прямоугольника вычисляет его площадь, периметр и диагональ.

# Задание 12. Средний уровень

### Условие

Ввести стоимость товара, количество единиц и процент скидки. Рассчитать первоначальную стоимость, сумму скидки и итоговую стоимость.

### Теоретические сведения

Первоначальная стоимость товара определяется по формуле:

**C = price · quantity**

Сумма скидки:

**D = C · discount / 100**

Итоговая стоимость:

**F = C − D**

где:

* `price` — стоимость одной единицы товара;
* `quantity` — количество единиц;
* `discount` — процент скидки;
* `C` — первоначальная стоимость;
* `D` — сумма скидки;
* `F` — итоговая стоимость.

### Код программы

```cpp
#include <iostream>
using namespace std;

int main() {
    double price, discount;
    int quantity;

    cout << "Введите стоимость одной единицы товара: ";
    cin >> price;

    cout << "Введите количество единиц: ";
    cin >> quantity;

    cout << "Введите процент скидки: ";
    cin >> discount;

    double initialCost = price * quantity;
    double discountSum = initialCost * discount / 100;
    double finalCost = initialCost - discountSum;

    cout << "Первоначальная стоимость: " << initialCost << endl;
    cout << "Сумма скидки: " << discountSum << endl;
    cout << "Итоговая стоимость: " << finalCost << endl;

    return 0;
}
```

### Результат работы

Например, стоимость одной единицы товара — `2000`, количество — `3`, скидка — `10%`.

Расчёт:

* первоначальная стоимость: `2000 · 3 = 6000`;
* сумма скидки: `6000 · 10 / 100 = 600`;
* итоговая стоимость: `6000 − 600 = 5400`.

### Вывод

В результате выполнения задания была разработана программа для расчёта стоимости покупки с учётом заданного количества товара и процентной скидки.

# Задание 18. Повышенный уровень

### Условие

Ввести пятизначное число. Найти сумму его цифр и сформировать число с обратным порядком цифр. Строки и циклы не использовать.

### Теоретические сведения

Для получения отдельных цифр пятизначного числа используются операции целочисленного деления `/` и нахождения остатка `%`.

Например, для числа `12345`:

* первая цифра: `12345 / 10000 = 1`;
* вторая цифра: `12345 / 1000 % 10 = 2`;
* третья цифра: `12345 / 100 % 10 = 3`;
* четвёртая цифра: `12345 / 10 % 10 = 4`;
* пятая цифра: `12345 % 10 = 5`.

Сумма цифр:

**1 + 2 + 3 + 4 + 5 = 15**

Обратное число:

**54321**

### Код программы

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;

    cout << "Введите пятизначное число: ";
    cin >> n;

    int a = n / 10000;
    int b = n / 1000 % 10;
    int c = n / 100 % 10;
    int d = n / 10 % 10;
    int e = n % 10;

    int sum = a + b + c + d + e;
    int reverse = e * 10000 + d * 1000 + c * 100 + b * 10 + a;

    cout << "Сумма цифр: " << sum << endl;
    cout << "Число в обратном порядке: " << reverse << endl;

    return 0;
}
```

### Результат работы

Для входного числа `12345` программа выдаёт:

```text
Сумма цифр: 15
Число в обратном порядке: 54321
```

При выполнении задания не использовались строки и циклы. Для обработки цифр применялись только арифметические операции.

### Вывод

В результате выполнения задания была создана программа, которая получает пятизначное число, определяет сумму его цифр и формирует число с обратным порядком цифр. Условие об отсутствии строк и циклов выполнено.
