ЛАБОРАТОРНАЯ РАБОТА №13 — ВАРИАНТЫ 3, 9 И 16

Содержимое архива:
1. variant_3_book_catalog.py — каталог книг.
2. variant_9_text_editor.py — редактор текста с отменой изменений.
3. variant_16_task_scheduler.py — планировщик с обычной и срочной очередями.


Как запустить:
1. Установите Python 3.
2. Распакуйте архив в отдельную папку.
3. Откройте терминал в этой папке.
4. Запустите нужную программу командой:
   python variant_3_book_catalog.py
   python variant_9_text_editor.py
   python variant_16_task_scheduler.py



Программы сохраняют данные в JSON-файлы рядом со скриптами.
Для запуска не требуются сторонние библиотеки.
